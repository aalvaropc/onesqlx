# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1, as its code of conduct.

In short: participate respectfully, assume good faith, and remember that
everyone here is spending their own time on this. Harassment, personal attacks,
and demeaning comments are not welcome.

## Reporting

If you experience or witness unacceptable behaviour, report it privately to the
project maintainer through a
[GitHub private message](https://github.com/aalvaropc) or by opening a
[private security advisory](https://github.com/aalvaropc/onesqlx/security/advisories/new)
if you prefer a confidential channel with a paper trail.

All reports are reviewed and handled confidentially. Maintainers may remove
comments, reject contributions, or block accounts that violate this code.
